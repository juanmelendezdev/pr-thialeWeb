Propuesta Comercial

Desarrollo de Plataforma E-commerce con Pasarela de Pago

Resumen del Proyecto

Desarrollo de una aplicación web moderna orientada al comercio electrónico, que incluye un carrito de compras interactivo y una pasarela de pago segura para procesar transacciones. El sistema estará diseñado para ser rápido, escalable y con una experiencia de usuario de primer nivel.

Detalles Técnicos

El proyecto se construirá utilizando tecnologías líderes en el mercado:

Angular (Frontend) Spring Boot (Backend) PostgreSQL 17 (Base de Datos) Vercel Free Tier (Hosting) GitHub (Repositorio)

Servicios Incluidos

  • Configuración de Dominio.
  • Despliegue y Configuración de Hosting.
  • Integración de Pasarela de Pago segura.
  • Garantía: 1 año de mantenimiento del sistema.

Cronograma de Desarrollo (7 Días)

Día 1 - 3: Primer Avance (50%)

Desarrollo de la estructura base, diseño de interfaces (Frontend), modelado de base de datos y configuración inicial del servidor. Presentación funcional al cliente.

Día 4 - 7: Entrega Final (100%)

Integración de la pasarela de pago, lógica del carrito de compras, conexión completa con la base de datos, despliegue final y configuración de dominio.
